# PlantFinder

PlantFinder est une application web permettant aux utilisateurs de rechercher des plantes, d'identifier des images de plantes via l'API Plant.id, et de visualiser des informations détaillées sur leurs caractéristiques. Le projet vise à simplifier l'identification des plantes et à fournir une base de données complète et interactive.

---

## Fonctionnalités principales
- Recherche avancée de plantes par mots-clés, famille, genre, ou conservation.
- Identification des plantes via téléchargement d'images grâce à l'API Plant.id.
- Affichage détaillé des informations sur les plantes : nom scientifique, famille, taille maximale, et plus.
- Ajout de plantes aux favoris pour un accès rapide.
- Géolocalisation pour enregistrer l'emplacement de plantes identifiées.
- Gestion des profils utilisateurs avec authentification sécurisée.
- Possibilité de laisser des commentaires et des évaluations.

---

## Technologies utilisées

### Frontend
- **React** : Framework pour construire une interface utilisateur moderne et dynamique.
- **Tailwind CSS** : Framework CSS pour un design réactif et élégant.

### Backend
- **Node.js** : Serveur backend pour gérer la logique de l'application.
- **Express** : Framework pour créer une API RESTful.
- **MongoDB** : Base de données NoSQL pour stocker les données des plantes et des utilisateurs.

### API Externe
- **Plant.id** : Intégration pour la reconnaissance des images et l'évaluation de la santé des plantes.

---

## Installation et exécution

### Prérequis
- Node.js (v16 ou supérieur)
- MongoDB
- Clé API pour l'API Plant.id
